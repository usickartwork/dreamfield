## 1. TUJUAN MANUAL BOOK

Buku panduan (*manual book*) ini disusun untuk memandu pengunjung umum, calon pemain pemula, maupun komunitas skirmish dalam menggunakan seluruh fitur interaktif pada website resmi Dreamfield Tactical Surabaya (`https://dreamfield.vercel.app`). 

Panduan ini menjelaskan alur operasional mulai dari membuka website, mencoba game simulasi menembak, memilih paket arena, melakukan reservasi jadwal, hingga menyelesaikan konfirmasi melalui WhatsApp Admin.

## 2. PERSIAPAN DAN AKSES WEBSITE

### Persyaratan Perangkat dan Peramban (*Browser*)
- **Perangkat**: Smartphone (Android / iOS), Tablet, Laptop, atau PC Desktop.
- **Peramban yang Direkomendasikan**: Google Chrome, Mozilla Firefox, Safari, Microsoft Edge, atau Opera versi terbaru.
- **Koneksi Internet**: Akses internet stabil (minimal 3G/4G atau WiFi publik).
- **Aplikasi Pendukung**: Memiliki aplikasi WhatsApp aktif pada smartphone atau WhatsApp Web pada komputer desktop untuk menyelesaikan alur konfirmasi reservasi.

### Cara Membuka Website
1. Buka aplikasi web browser pada perangkat Anda.
2. Ketikkan alamat website resmi pada bilah alamat (*address bar*):
   ```
   https://dreamfield.vercel.app
   ```
3. Tekan tombol **Enter** atau **Go**. Halaman utama website akan mulai dimuat.

## 7. PANDUAN MINI SHOOTING RANGE SIMULATOR

Website Dreamfield menyediakan game simulasi menembak virtual 3 level bertarget acak langsung di browser untuk menguji refleks akurasi Anda sebelum bermain di arena nyata.

```
+-----------------------------------------------------------+
| [ STEP 1 / 3 ]   [ STOPWATCH: 10s ]   [ GOAL: 0/4 ]       |
| MAG: 15/15       ACC: 100%            SCORE: 0000         |
+-----------------------------------------------------------+
|                                                           |
|       [BUNKER 01]       ( TARGET )      [BUNKER 02]       |
|                                                           |
+-----------------------------------------------------------+
| [!] STEP 1: Kenai sasaran baja 4 kali sebelum 10 detik!   |
|                 [ RELOAD MAGASIN (15 BBs) ]               |
+-----------------------------------------------------------+
```
`[Screenshot 06 — Antarmuka Permainan Mini Shooting Range Simulator]`

### Langkah Bermain Simulator:
1. Gulir layar ke bagian **"Mini Shooting Range"** pada halaman utama.
2. Simulator berada dalam kondisi siaga (*Ready Gate*). Waktu tidak akan berjalan sebelum Anda siap.
3. Klik tombol hijau **`READY · MULAI GAME (10S)`**. Batas waktu 10 detik akan mulai menghitung mundur.
4. **Level 1 — IPSC Steel Popper**:
   - Sasaran plat baja akan bergerak ke kiri dan ke kanan secara dinamis.
   - Arahkan kursor atau ketuk sasaran baja sebanyak **4 kali** sebelum waktu 10 detik habis.
5. **Level 2 — Sprint Bullseye**:
   - Sasaran lingkaran konsentris bergerak cepat dan sesekali bersembunyi di balik barikade beton taktis.
   - Tembak bagian sasaran sebanyak **5 kali** saat sasaran muncul dari balik perlindungan.
6. **Level 3 — CQB Hostile vs Civilian Hostage**:
   - Sasaran akan menampilkan musuh bersenjata (*Hostile*) dan sandera warga sipil (*Civilian Hostage*).
   - **Tembak Siluet Musuh**: Tembak kepala musuh untuk skor +50, atau dada musuh untuk skor +25. Target: 6 hit musuh.
   - **JANGAN TEMBAK SANDERA**: Jika Anda menembak sandera sipil (*simbol X / tanda bahaya*), Anda akan dikenakan penalti pelanggaran (*PENALTY*).
7. **Isi Ulang Amunisi (*Reload Magazine*)**:
   - Magasin Anda berisi 15 butir peluru BB virtual.
   - Jika amunisi habis, klik tombol besar **`RELOAD MAGASIN`** di bagian tengah bawah arena untuk mengisi ulang peluru ke 15 butir kembali.
8. **Pengamanan Layar Zoom**: Jika Anda memperbesar layar browser (*browser zoom* > 100%), game akan menampilkan peringatan dan mengunci tembakan hingga zoom dikembalikan ke 100% normal.

> [!NOTE]
> Suara efek tembakan pada simulator ini telah dinonaktifkan (*silent*) agar tidak mengejutkan pengunjung saat membuka website di tempat umum.

### Tahap 1: Memilih Kategori Arena
1. Pada bagian **Tahap 1: Pilih Kategori / Arena**, klik salah satu dari 5 kartu kategori:
   - *War Game CQB*: Pertempuran taktis tim di arena 1.200 m².
   - *Shooting Target*: Latihan akurasi sasaran kertas dan baja reaktif.
   - *Tactical Coaching*: Kelas bimbingan teknik pertempuran oleh instruktur.
   - *Unit Coaching & Drill*: Pelatihan mekanika unit GBB & AEG.
   - *Tactical Gear Rental*: Sewa perlengkapan proteksi ekstra.
2. Kartu yang Anda pilih akan menyala dengan border hijau (*Electric Lime*) dan badge nomor tahap akan berubah menjadi tanda centang hijau.
3. Di bawah kartu kategori, kartu pratinjau arena (*Arena Real Preview*) akan otomatis memunculkan foto asli arena, luas area, dan fasilitas pendukungnya.

---

### Tahap 2: Memilih Paket Permainan
1. Setelah kategori arena dipilih, sistem akan memunculkan daftar kartu paket permainan yang tersedia di bawahnya.
2. Setiap kartu paket memuat informasi transparan:
   - Nama paket dan platform unit (misal: *Airsoft AEG M4 CQB* atau *Gas Blowback Pistol*).
   - Biaya paket (misal: *Rp 150.000 / Orang / Jam*).
   - Badge keunggulan (seperti *BEST VALUE* atau *TERPOPULER*).
   - Daftar fasilitas yang sudah termasuk (amunisi BB, rompi, masker, free flow air mineral).
3. Klik pada kartu paket yang Anda inginkan. Kartu paket akan terpilih dengan indikator tanda centang.

---

### Tahap 3: Menentukan Jadwal dan Jumlah Pemain
1. **Pilih Tanggal Main (`Tanggal Main`)**:
   - Klik kolom tanggal. Kalender akan muncul.
   - Sistem tidak mengizinkan pemilihan tanggal di masa lalu.
   - **PENTING: Jangan Memilih Hari Selasa!** Arena Dreamfield tutup setiap hari Selasa untuk perawatan unit rutin. Jika Anda memilih hari Selasa, sistem akan menampilkan peringatan merah dan menolak jadwal tersebut.
2. **Pilih Jam Kedatangan (`Jam Sesi`)**:
   - Buka menu dropdown jam kedatangan.
   - Pilih jam sesi yang Anda inginkan antara pukul **12:00 WIB sampai 21:00 WIB**.
3. **Pilih Jumlah Personel (`Jumlah Personel`)**:
   - Ketuk tombol plus (`+`) atau minus (`-`) untuk menyesuaikan jumlah orang dalam rombongan Anda (minimal 1 orang).

---

### Tahap 4: Mengisi Data Diri Pemesan
1. **Nama Lengkap Pemesan**: Masukkan nama Anda (misal: *Budi Santoso*).
2. **Nomor WhatsApp**: Masukkan nomor telepon WhatsApp Anda yang aktif (misal: *081234567890*).
3. **Catatan Khusus (Opsional)**: Masukkan permintaan khusus jika ada (misal: *"Bawa tim kantor 8 orang, minta rompi ukuran L"*). Jika tidak ada, biarkan terisi tanda `-`.

## 12. PANDUAN LAYANAN CHATBOT AI "MINDREAM"

Website Dreamfield dilengkapi asisten virtual cerdas bernama **Mindream** yang dapat membantu menjawab pertanyaan seputar arena selama 24 jam.

`[Screenshot 11 — Widget Obrolan Asisten Virtual AI Mindream]`

### Cara Menggunakan Chatbot Mindream:
1. Perhatikan sudut kanan bawah layar Anda pada halaman utama (`index.html`).
2. Klik tombol kapsul melayang bertuliskan **"Tanya Mindream • Online 24/7"** di pojok kanan bawah. Jendela obrolan taktikal akan terbuka.
3. **Menggunakan Pertanyaan Cepat (*Quick Action Chips*)**:
   - Pada awal obrolan, Anda dapat langsung mengklik salah satu tombol pintasan:
     - 📍 *Lokasi & Jam Buka*
     - 💰 *Daftar Harga Paket*
     - 🛡️ *Arena & Aturan Safety*
     - 📅 *Cara Booking*
4. **Mengetik Pertanyaan Bebas**:
   - Ketik pertanyaan Anda pada kolom input di bagian bawah (misal: *"Apakah pemula boleh main war game?"* atau *"Apakah boleh bawa unit airsoft sendiri?"*).
   - Tekan tombol Enter atau klik ikon pesawat kertas hijau.
5. **Membaca Balasan**:
   - Mindream akan menampilkan animasi mengetik alami (*paced typing*) selama 1,5–3,0 detik selayaknya admin manusia sungguhan.
   - Balasan disajikan secara ringkas menggunakan poin-poin rapi.
   - Jika Mindream mengirim 2 atau 3 balon pesan sekaligus, layar Anda **tetap terkunci pada balon pertama** agar Anda nyaman membaca dari atas.
   - Jika terdapat pesan baru di bagian bawah yang belum terlihat, tombol kapsul mengambang **`[ ↓ Pesan baru di bawah ]`** akan muncul. Klik tombol tersebut untuk meluncur ke dasar obrolan.
6. **Tombol Booking Otomatis (*Smart Booking CTA*)**:
   - Jika dalam percakapan Anda menyatakan ingin memesan (contoh: *"saya mau booking slot"*), Mindream akan secara otomatis menyertakan tombol hijau **`Booking Sekarang`** yang langsung membawa Anda ke halaman formulir booking.
7. **Pengaturan Efek Suara**:
   - Klik ikon speaker di bagian header chat untuk menyalakan atau mematikan efek bunyi radio taktikal.
8. **Menutup Obrolan**:
   - Klik ikon silang (`✕`) di pojok kanan atas jendela chat.

> [!NOTE]
> Mindream merupakan asisten cerdas berbasis Artificial Intelligence (AI). Untuk hal-hal khusus seperti konfirmasi pembayaran uang muka, penyesuaian jadwal mendadak, atau reservasi korporat skala besar di atas 50 orang, disarankan menghubungi admin manusia langsung melalui WhatsApp.

## 15. PEMECAHAN MASALAH UMUM (TROUBLESHOOTING)

| Gejala Masalah | Penyebab | Solusi Tindakan |
